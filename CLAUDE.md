# CLAUDE.md — Project Rules for AI Sessions

## Commit and push

**Never commit or push without explicit instruction from the user.**

Do not commit or push after completing a wave of work, even if it feels like a natural stopping point. Always stop, summarise what has changed, and wait for the user to say "commit" or "push" before doing so.

This applies especially after sessions involving multiple file changes, new documents, or structural updates to the spec.
