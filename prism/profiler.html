Prospect intake

Ten questions for any tool a prospect runs

Ask these in discovery. The answers set the connector pattern, the time to first report, and whether action push is possible.

  • Which record types live in it?Incidents, hazards, inspections, actions, investigations, permits. Map each to a Prism source type.
  • Is API access included or a paid add-on?Several vendors enable API access per contract. This affects both price and lead time.
  • Can we filter by modified date?Without a modified-since filter, polling means full re-reads. Plan on a daily extract instead.
  • Does it send webhooks, and for which events?Webhooks enable the minutes-level direct path. Check whether payloads are complete or need a follow-up fetch.
  • Who can issue credentials, and with what scope?Read-only service accounts are preferred. Note any vendor-issued IDs, such as Ideagen's ConsumerId.
  • Are custom fields exposed?Configured platforms often keep the narrative in a custom field. The field map depends on it.
  • How are sites and org units represented?Projects, locations and business units need mapping to site, region and division.
  • What are the rate limits?Sets how long the 12-month backfill takes.
  • Can we create actions through the API?Action push depends on this. Otherwise use the fallback tracker.
  • Where is the data hosted, and are there export restrictions?Data residency requirements and any customer rules against third-party processing.
