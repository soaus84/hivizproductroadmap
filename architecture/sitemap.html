View patterns in use
Dashboard8 views
Multi-source data assembled for a specific role and context. Adapts to enabled workspaces — layers visible based on workspace_config.
Supervisor home · Worksite dashboard · Enquiry results · Analytics · Survey results · Capacity profile · Alert view
List9 views
Scrollable list of items with status-driven styling. Overdue earns critical colour. Tap to navigate to detail or trigger action.
Observation records · Actions · Sites · Incidents · Pending controls · Pending docs · Verification queue · Manager home
Detail11 views
Full specification of a single entity. Often master-detail on desktop (list left, detail right). AI rationale always inline. State-based content in some views.
Observation detail · Insight panel · Investigation · Control detail · Document detail · Talk delivery · Visit briefing · Session complete
Form11 views
Data capture or configuration. Mobile forms optimised for one-thumb use. Desktop forms use full-width layouts. Always-optional AI assist where available.
Capture · Incident report · Not In Place · Login · Settings · Document upload · Enquiry builder · Regulatory notification
Wizard7 views
Multi-step progressive forms. One thing at a time. Progress indicator top right. Back navigation always available. Used where sequence matters.
Plan a visit · Enquiry response · Active verification · Survey response · Context question · Survey builder
Kanban1 view
Four-column pipeline. pipeline_stage is an explicit DB column — written on card move. No derived state. Detail panel slides in on tap without navigation.
Insights pipeline (Prioritise → Learn → Improve → Resolved)
Table7 views
Desktop-primary data tables. Inline status chips. Health bars as table cells. Filter + sort. Click row to navigate. Status columns show workspace health.
Register table · Users · Action tracker · Document library · Atrophy dashboard · Incident list
Map / Diagram3 views
Spatial information display. Bowtie is the primary example — three-column with hazard at centre. Atrophy heatmap is grid-based. Both use status colour discipline strictly.
Bowtie · Atrophy heatmap · Capacity profile (factor grid)
PipelineUsed in 4 flows
The core intelligence loop as a sequential pipeline. Observation → Enrich → Trend → Insight → Approve → Talk → Deliver → Action. Visible in analytics, not a view itself.
Pipeline health analytics · AI flow diagram · Workbench queue ordering
ModalUsed throughout
Overlays for confirmations, quick actions, and compact detail. Never used for multi-step flows — those are wizards. Closed on backdrop tap.
Confirm completion · Deliver talk confirmation · Accept/reject control · Add question
